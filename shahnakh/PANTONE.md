# Pantone TCX reference UI

The 12 existing artistic RGB swatches are preserved. Their TCX associations are editorial suggestions, not licensed Pantone RGB values or exact matches. Arbitrary picker colors retain their chosen RGB preview and receive the associated TCX suggestion of the closest of these 12 display swatches (OKLab Euclidean distance). This is explicitly NOT a nearest match against the entire Pantone catalog. All visible references and enquiry data say approximate. Code entry accepts only the 12 supported references, including Persian digits; unknown codes leave the selected color unchanged. Screen matches must be checked with the physical cotton card and fabric sample.

TCX cotton system: https://www.pantone.com/na/en-us/products/fashion-home-interiors/cotton-swatch-card
