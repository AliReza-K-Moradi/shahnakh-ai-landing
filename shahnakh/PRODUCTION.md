# Shahnakh — bilingual release candidate

این بسته نسخهٔ آمادهٔ اتصال و انتشار فرانت‌اند است. قبل از معرفی به‌عنوان سایت عملیاتی، موارد باز زیر را تکمیل کنید. فایل `index.html` فارسی و `en.html` انگلیسی است؛ هر دو بدون ابزار build باز می‌شوند.

## راه‌اندازی

1. محتوای همین پوشه را در ریشهٔ مخزن یا پوشهٔ سایت قرار دهید. `assets` را جابه‌جا نکنید.
2. برای GitHub Pages، شاخهٔ main و مسیر root را انتخاب کنید. فایل `.nojekyll` در بسته وجود دارد.
3. وب‌سایت را با HTTPS باز کنید. برای فعال‌کردن حرکت موبایل، دکمهٔ «حرکت با گوشی / Enable tilt» را لمس کنید. مجوز فقط بعد از این لمس درخواست می‌شود. حرکت به‌صورت پیش‌فرض خاموش است و به‌طور محلی پردازش می‌شود؛ دادهٔ حسگر جایی ارسال یا ذخیره نمی‌شود.
4. زبان را با EN / فا عوض کنید. رنگ انتخابی و محل بخش در URL منتقل می‌شود؛ اطلاعات شخصی فرم ذخیره نمی‌شود.

## اتصال فرم — هنوز انجام نشده

در `config.js` آدرس endpoint تیم خود را قرار دهید. پیش‌فرض خالی است؛ فرم فقط اعتبارسنجی می‌کند و هیچ درخواست واقعی ارسال نمی‌کند. شماره تماس و تلگرام مسیرهای فعال ارتباط هستند. تا زمان اتصال، عبارت «ثبت آنلاین هنوز فعال نشده» عمداً نمایش داده می‌شود.

قرارداد endpoint: درخواست POST با JSON شامل fullName، brandName، mobile (شمارهٔ ایرانی نرمال‌شده)، fabric، monthlyKg (عدد)، selectedColor (مرجع تقریبی TCX)، source و consent. موفقیت فقط با HTTP 2xx و بدنهٔ `{"success":true}` پذیرفته می‌شود. برای خطا یا timeout، اطلاعات کاربر در فرم باقی می‌ماند. سرور باید اعتبارسنجی مستقل، مقابله با ارسال تکراری/اسپم، محدودیت نرخ، HTTPS، سیاست نگهداری اطلاعات و در صورت نیاز CORS دامنهٔ سایت را پیاده کند. کلید خصوصی یا secret را در فایل‌های عمومی نگذارید. GitHub Pages به‌تنهایی این backend را فراهم نمی‌کند.

## تغییر محتوا

منبع فارسی `index.html`، `assets/app.js` و `assets/palette.js` است. متن‌های انگلیسی در `src/build-english.py` تعریف شده‌اند؛ با Python اجرا کنید تا en.html و app.en.js و palette.en.js به‌روز شوند. برای CSS از Tailwind CLI نسخهٔ 4 استفاده کنید: ورودی src/input.css و خروجی assets/styles.css. فایل CSS کامپایل‌شده آماده است؛ برای نمایش به Node یا Python نیاز نیست.

## محدودیت‌های شفاف

- حرکت پارچه مدل بصری محدود و برگشت‌پذیر است، نه شبیه‌سازی فیزیکی آزمایشگاهی. لبهٔ پایین یک سطح برش نازک دارد؛ هندسهٔ لوله‌ای حذف شده است.
- حسگر روی همهٔ مرورگرها موجود نیست. رد مجوز، نبود حسگر یا کاهش حرکت، استفاده از رنگ‌ها و لینک‌ها را متوقف نمی‌کند. حسگر هنگام خروج از صفحه متوقف می‌شود؛ کالیبراسیون با جهت جدید صفحه از نو انجام می‌شود.
- ۱۲ کد TCX فقط مرجع پیشنهادی‌اند. تبدیل رسمی کل کاتالوگ پنتون یا تطبیق قطعی رنگ تولید نیستند. رنگ و موجودی نهایی باید با نمونه تأیید شود.
- تصاویر و تکسچرها با AI تولید شده‌اند و عکس محصول واقعی موجودی نیستند.
- نام، لوگو و اطلاعات تجاری شاه‌نخ در نسخه موجود است. در معرفی نمونه‌کار، نقش برند و استفاده از AI را شفاف بنویسید.

## موارد باز پیش از انتشار عملیاتی

- اتصال و آزمون واقعی endpoint فرم.
- بازبینی بصری در Chrome/Edge و Safari، در عرض‌های 360، 390، 820، 1024 و 1440؛ این محیط امکان تأیید تصویری نهایی را نداد.
- تست حسگر در گوشی iOS و Android واقعی روی HTTPS: اجازه/رد، حالت افقی، خاموش/روشن، تعویض تب، کاهش حرکت و مصرف باتری.
- سنجش عملکرد GPU/FPS، Lighthouse و کنتراست روی خروجی رندرشده؛ آزمون DOM یا هندسه جای آن را نمی‌گیرد.
- پس از مشخص‌شدن URL، canonical و متادیتای اشتراک‌گذاری و QR نهایی را تنظیم کنید.

مرجع رفتار حسگر: https://developer.mozilla.org/en-US/docs/Web/API/DeviceOrientationEvent/requestPermission_static
